What it finds

  • PERSON names of people
  • LOCATION places and addresses
  • ORGANIZATION offices, companies, parties
  • DATE days, months and years
  • PHONE mobile and landline numbers
  • EMAIL e-mail addresses
  • CITIZENSHIP_NO citizenship certificate numbers
  • NATIONAL_ID national identity numbers
  • PAN permanent account numbers
  • PASSPORT_NO passport numbers
  • LICENSE_NO driving licence numbers
  • VOTER_ID voter card numbers
  • BANK_ACCOUNT bank account numbers
  • VEHICLE_PLATE number plates

It reads Devanagari and Nepali written in Latin letters, with digits of either kind. It was tested mostly on Devanagari.

Exact: start, end and label all right. Whole words: the same after every span is widened to whole words, which forgives a case marker left on a name. Characters found: the share of the characters of names inside any span found.

The labels were written with the help of an AI assistant and are waiting for a review by a native speaker, so the scores may move. Every system, the second test set and the method are in the full benchmark.

Use it

In Python, with no graphics card:

Python
# pip install onnxruntime tokenizers numpy huggingface_hub
import sys
from huggingface_hub import snapshot_download
folder = snapshot_download("fiste-ai/gopya")
sys.path.insert(0, folder)
from gopya import Gopya

pii = Gopya(folder)
pii.redact("मेरो नाम सीता थापा हो, फोन ९८४१२३४५६७।")
# मेरो नाम [PERSON_1] हो, फोन [PHONE_1]।

In a web page, load web/gopya.js from the model page; this page is the example. Weights CC BY-NC 4.0, code MIT. It is a helper and not a guarantee: on news it misses about 6 in 100 characters of personal data, and more on text that is unlike news.
